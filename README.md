# About This Task
This assignment is a desktop puzzle game. A loaded image is cut into a scrambled grid of tiles. The image starts as a complete picture, then gets scrambled by moving, rotating, and flipping the pieces. The player clicks the tiles to restore the picture, while the application tracks moves, offers hints, and detects when the picture is fully restored.

The project is built around three main areas:

OOP Design The classes that represent a tile, the grid of tiles, and the different ways a tile can be scrambled (swap, rotate, flip).

Image Processing (OpenCV) Loading an image, resizing and cropping it to fit the chosen grid size, splitting it into tiles, and reassembling the tiles back into one picture.

Tkinter GUI and Gameplay The on screen display, click handling, moves and score tracking, hints, and the solve button.
